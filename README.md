# Explainable-Deep-Learning-Framework-for-Skin-Cancer-Classification
The emerging field of Explainable Artificial Intelligence (XAI) seeks to enhance model transparency by revealing how deep learning models arrive at their decisions.By combining predictive power with interpretability, XAI ensures that clinicians can understand, validate, and trust AI-assisted diagnostic outcomes. This project aims to design and implement an Explainable AI-based skin lesion classification system using the HAM10000 (“Human Against Machine”) dataset. The proposed framework leverages a ResNet50 architecture for image classification and incorporates Grad-CAM (Gradient-weighted Class Activation Mapping) and SHAP (SHapley Additive exPlanations) to visualize and interpret model predictions. The objective is to build a system that not only achieves high diagnostic accuracy but also provides transparent and interpretable explanations aligned with clinical reasoning thereby bridging the gap between artificial intelligence and real-world dermatological practice.
